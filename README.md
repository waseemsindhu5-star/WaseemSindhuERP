# Waseem Sindhu ERP

A modern offline Windows ERP built with .NET 8 + WPF + SQL Server LocalDB.

## Features planned
- Login and user roles
- Company setup
- Customer and supplier management
- Item / product catalog
- Sales orders and sales invoice
- Delivery challan
- Purchase orders and invoices
- Inventory and stock tracking
- Ledger and accounting entries
- Profit/Loss and Balance Sheet reports
- Modern dashboard and business overview

## Recommended stack
- .NET 8
- WPF (Desktop)
- SQL Server LocalDB / SQL Server Express
- Entity Framework Core
- MVVM architecture

## Project structure
- `src/WaseemSindhuERP` - main desktop app
- `docs` - schema and planning files

## Run locally
1. Open the project in Visual Studio 2022.
2. Restore NuGet packages.
3. Set `WaseemSindhuERP` as startup project.
4. Press F5 to run.
5. SQL Server LocalDB will create the database automatically on first run.
